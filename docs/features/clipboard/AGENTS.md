# Clipboard test ownership

- Keep one primary test owner for each contract. Keep another layer only when
  it reaches a different platform, storage, permission or lifecycle risk.
- A fake callback must not supply the publication or stored result the test
  claims to prove. Use the real manager and platform boundary for share replay.
- Change paste ports between calls when checking that the latest ports are
  used. A display-label test does not prove what reaches the editor.
- Check that null observations are delivered, not just that a destination is
  null. Keep timeouts outside catches that expect an owner's failure.
- Pair malformed-source rejection with a successful platform read of that
  same source and independent foreign-provider read counters.
- Retain real URI grants, historical migrations and durable media roots.
  Restore the prior platform clip and its roots before unlinking test media.
  Keep baseline failures visible; do not turn them into deletion candidates.
- Before retiring weaker proof, carry its unique assertions into the keeper
  and show that a deliberately broken owner makes that keeper fail.
